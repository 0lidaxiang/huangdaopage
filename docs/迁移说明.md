# 迁移说明

## 范围与实现

源仓库为同级 `huangdao`，本轮开始时位于干净的 `main` 分支，HEAD 为 `88d5243`，远程为 `0lidaxiang/huangdao`。目标仓库为 `huangdaopage`，初始为空仓库，远程为 `0lidaxiang/huangdaopage`；当前本地分支与 GitHub 默认分支均为 `master`。所有迁移代码、脚本、文档与输出均在目标目录，源仓库与原数据库保留不变。

已阅读 V1.2 产品规划、设计说明、运行与部署、前端公开页面、后端 model/store/server、内容包和导入脚本，并实际查看首页亮色、暗色、深度与演化四张原图。复用 React 页面和 CSS，保留首页主视觉、主内容及侧栏、深度列表/阅读、演化地图、蓝色强调和亮暗主题。灯塔图单独提取为小型 WebP，不把整张设计稿当页面，不使用原图中的示例二维码。

依赖沿用源锁文件：React/React DOM 18.3.1、TypeScript 5.8.3、Vite 6.4.3、React Router DOM 7.18.3。未升级框架主版本或引入新的站点生成框架。Vite 构建浏览器模块，另在本机/构建环境用 React `renderToString` 生成全部公开 HTML，SSR 编译临时目录不会进入产物；部署后只有静态文件。

## 数据来源与公开边界

权威来源为本机 MySQL `huangdao.site_state.id=1.payload`，通过只读事务导出。导出结果、真实导出时间和快照哈希以 `content/provenance.json` 为准。完整记录状态和历史差异在 `.private/migration-audit.json`，公开清单仅包含已符合原站发布规则的记录。

调查确认各来源并非同一份数据：`backend/data/site.json` 不存在；历史独立预览只有 46 条公开记录；2026-09-10 的历史 MySQL 导入后快照有 120 条记录、当时公开 100 条。这些数字仅描述历史文件，不能据此宣称当前数据库迁移数量。全部历史 JSON 与内容包都进入盘点，未自动替代或合并进当前数据。

数据库中的改稿优先于旧内容包。对同 ID 的差异记录具体字段，对同路径不同 ID 的情况记录路径冲突；不同 ID 的同题材文章保留各自身份，不自动去重删除。草稿、下线、回收站及未来记录不复制到公开内容或静态文件。只移除推荐和关联配置中指向非公开内容的 ID，不改写文章正文或真实日期。

公开记录保留标题、摘要、正文、作者、发布时间、更新日期、历史年份、人物、来源、分类、话题、SEO、ID 和 slug。正文中的示例说明及历史事件日期原样保留。公众号读取真实站点设置；二维码未配置时显示“二维码待配置”。

## 页面与交互

覆盖首页、信号列表/详情、深度列表/详情、演化总览/四条路线/节点、话题列表/详情、搜索、关于与咨询。后台登录、写库和上传入口不迁移。

所有公开文章可从列表、话题、搜索及关联内容抵达；演化节点按路线、阶段、事件/年代/人物筛选，保留原排序。搜索支持标题、摘要、全文、作者、来源、话题、人物和年份；标题匹配权重 10、摘要权重 3，同分按发布时间倒序，时间排序直接按日期倒序。今天/自然周/自然月以 Asia/Shanghai 计算，周一为一周起点。

HTML 包含完整安全渲染的正文及独立 SEO，浏览器站内导航时按需读取目标文章 JSON。首页不加载全部正文或全文搜索索引；搜索发生时才读取完整公开正文索引，Markdown/高亮模块按需加载。亮暗主题保存在浏览器本地；存储不可用时使用配置中的默认主题。

详情直接访问和刷新读取对应目录的静态 HTML，未知路径返回专门的 404。支持根域与显式子路径构建，资源和路由统一使用 Vite base。EdgeOne 配置依据及正式域名变量见[部署说明](部署说明.md)。

## 对账与复现

1. `npm run content:audit` 盘点来源，不连接数据库或改变公开内容。
2. `npm run content:export` 读取当前 MySQL，生成公开内容源、逐篇正文及私密排除/差异报告。
3. `npm run content:check` 校验 ID/slug、正文哈希、分类关系、推荐、媒体、计数及旧服务引用。
4. `npm run build` 仅使用公开内容源生成 `dist/`。
5. `npm run test:e2e` 用真实 Chrome 枚举全部公开路径，检查无 JavaScript 阅读、刷新、站内链接、资源、交互、桌面/手机及亮暗主题，并保存截图/请求证据。
6. `npm run output:check` 核对产物中的正文和公开清单，检查私密原始记录未泄入产物，检查连接密码和管理密钥未进入可下载文件。

原始快照、私密配置、完整状态盘点、测试截图、构建产物和报告均被 `.gitignore` 排除。源码中的合成测试只在独立临时目录验证边界；其结果不充当真实迁移验收。
